NeoFluxLightweight Cross-Platform UI Framework

View on GitHub
🧩

Flutter-style Widgets

Build UIs with composable widgets. Override virtual functions to customize behavior. Route-based navigation.

📐

Taitank Flex Layout

Full flexbox support powered by Taitank. Row/column, justify, align, flex-grow, padding, margin.

🎨

tgfx Rendering

Mobile rendering via tgfx; desktop bridge to GLFW + OpenGL. SPSC lock-free queue between layers.

⚡

C++20 Coroutines

Native coroutine support for frame-based async work. Schedule tasks on the event loop.

🖥️

Cross-Platform

Windows, Linux, macOS desktop via GLFW. Mobile via tgfx. Single CMake build.

🔧

Engineering-Grade

glog/gflags logging, gtest unit tests, clang-tidy enforced, Google C++ style, pure ASCII source.
